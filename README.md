## 📘 Projects Overview

### **1. Libft** (`1_libft`) <img src="https://img.shields.io/badge/-C-007ACC?style=flat-square&logo=c&logoColor=white" height="20">&nbsp;

A custom implementation of essential C standard library functions. This project strengthens understanding of memory management, strings, and basic algorithms.

**Key skills:** Static libraries, memory handling, custom utility functions.

---

### **2. Born2BeRoot** (`2_Born2BeRoot`) <img src="https://img.shields.io/badge/-Linux-FCC624?style=flat-square&logo=linux&logoColor=black" height="20">&nbsp;

A project focused on system administration and security in Linux environments. Tasks include user management, permissions, firewalls, and network configuration.

**Key skills:**  
- Linux system administration  
- User & group management  
- File permissions & sudo  
- Network configuration & firewall (iptables, ufw)  
- Service management (systemctl, cron)  
- Security best practices

---

### **3. Printf** (`3_printf`) <img src="https://img.shields.io/badge/-C-007ACC?style=flat-square&logo=c&logoColor=white" height="20">&nbsp;

A full re-implementation of the standard `printf` function, supporting formatted output, variadic arguments, and custom conversions.

**Key skills:** Variadic functions, parsing, formatted output.

---

### **4. Get Next Line** (`4_GetNextLine`) <img src="https://img.shields.io/badge/-C-007ACC?style=flat-square&logo=c&logoColor=white" height="20">&nbsp;

Reads a line from a file descriptor efficiently, one line at a time—handling buffering, memory allocation, and multiple FDs.

**Key skills:** File descriptors, buffer management, stateful functions.

---

### **5. Pipex** (`5_pipex`) <img src="https://img.shields.io/badge/-C-007ACC?style=flat-square&logo=c&logoColor=white" height="20">&nbsp;

A recreation of shell piping behavior using processes and file redirections. Simulates `cmd1 | cmd2` via `fork`, `execve`, and `pipe`.

**Key skills:** Processes, pipes, file redirection, `execve`.

---

### **6. so_long** (`6_so_long`) <img src="https://img.shields.io/badge/-C-007ACC?style=flat-square&logo=c&logoColor=white" height="20">&nbsp;

A simple 2D game using the MiniLibX graphics library. Create a small map-based game with movement, collectibles, and win conditions.

**Key skills:** Basic graphics (MiniLibX), event handling, game loops.

---

### **7. push_swap** (`7_push_swap`) <img src="https://img.shields.io/badge/-C-007ACC?style=flat-square&logo=c&logoColor=white" height="20">&nbsp;

An algorithmic challenge to sort numbers using two stacks and a limited set of allowed operations.

**Key skills:** Sorting algorithms, data structures, optimization.

---

### **8. Philosophers** (`8_philo`) <img src="https://img.shields.io/badge/-C-007ACC?style=flat-square&logo=c&logoColor=white" height="20">&nbsp;

The classic Dining Philosophers problem exploring multithreading, mutexes, and timing constraints.

**Key skills:** Threads, mutexes, timing precision, deadlock avoidance.

---

### **9. Minishell** (`9_minishell`) <img src="https://img.shields.io/badge/-C-007ACC?style=flat-square&logo=c&logoColor=white" height="20">&nbsp;

A functional shell implementing command parsing, pipes, redirections, environment variables, built-ins, and more.  
This was a **group project**.

**Collaborators:**  
- [nataiuca](https://github.com/nataiuca)  
- [KarmaFaber](https://github.com/KarmaFaber)

**Key skills:** Parsing, process control, signals, environment handling.

---

### **10. NetPractice** (`10_NetPractice`) <img src="https://img.shields.io/badge/-Networking-007ACC?style=flat-square&logo=linux&logoColor=white" height="20">&nbsp;

A project oriented to networking concepts and practices. Focuses on configuring network services and understanding network protocols.

**Key skills:**  
- TCP/IP fundamentals  
- DNS, HTTP, SSH, FTP configuration  
- Packet analysis (tcpdump, Wireshark)  
- Network troubleshooting & diagnostics  
- Linux networking commands (ifconfig, ip, netstat)  
- Client-server configuration 

---

### **11. Cub3D** (`11_cub3D`) <img src="https://img.shields.io/badge/-C-007ACC?style=flat-square&logo=c&logoColor=white" height="20">&nbsp;

A basic 3D raycasting engine inspired by Wolfenstein 3D, rendering a first-person view from a 2D map.  
This was a **group project**.

**Collaborators:**  
- [JotaEmeDiaz](https://github.com/JotaEmeDiaz)  
- [KarmaFaber](https://github.com/KarmaFaber)

**Key skills:** Raycasting, vector math, textures, MiniLibX graphics.

---

### **12. C++ Modules** (`12_CPPs`) <img src="https://img.shields.io/badge/-C++-007ACC?style=flat-square&logo=cplusplus&logoColor=white" height="20">&nbsp;

A series of C++ exercises introducing OOP, polymorphism, memory models, templates, exceptions, and more.

**Key skills:** Object-oriented programming, C++ syntax and concepts.

---

### **13. Webserver** (`11_Webserver`) <img src="https://img.shields.io/badge/-C++-007ACC?style=flat-square&logo=cplusplus&logoColor=white" height="20">&nbsp;

This project is about writing an own HTTP server in C++.

**Key skills:**  
- HTTP/1.1 protocol implementation  
- Socket programming  
- Non-blocking I/O & multiplexing (poll/epoll/kqueue depending on OS)  
- Request parsing & response handling  
- CGI integration  
- Configuration file parsing  
- Server architecture & modular design

---

### **14. Inception** (`12_inception`) <img src="https://img.shields.io/badge/-Docker-2496ED?style=flat-square&logo=docker&logoColor=white" height="20">&nbsp;

This project aims to broaden system administration knowledge by using Docker. It involves virtualizing several Docker services and orchestrating them within a personal virtual machine.

**Key skills:**  
- Docker & Docker Compose  
- Container orchestration  
- Nginx configuration  
- WordPress + MariaDB deployment  
- Networking between containers  
- Volumes & persistent data  
- System administration & service isolation

---
